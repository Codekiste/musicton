### Installation

| System | Datei | Hinweis |
|---|---|---|
| Linux | `.deb` oder `.tar.gz` | `.deb`: `sudo apt install ./datei.deb`. `.tar.gz`: entpacken und `./install.sh` (ohne Root) ausführen |
| macOS | `.dmg` / `.pkg` | Noch nicht notarisiert: beim ersten Start Rechtsklick → „Öffnen“ |
| Windows | `-setup.exe` | Noch nicht signiert: bei SmartScreen auf „Weitere Informationen“ → „Trotzdem ausführen“ klicken |

Prüfsummen stehen in `SHA256SUMS.txt`. Musicton ist Cleanroom-Freeware (GPL-3.0-or-later), mehr unter [codekiste.dev](https://codekiste.dev).
